# KBC Quiz Game 🎯

A Python-based CLI quiz game inspired by Kaun Banega Crorepati (KBC).

---

## 🚀 Features

* Player-name login before starting the game
* 10 Multiple-choice questions
* Money reward system
* Safe levels (₹10,000 and ₹3,20,000)
* Quit option anytime
* Input validation

The login asks for a non-empty player name. It is a name-only sign-in and does
not create or store accounts.

---

## 🛠 Tech Used

* Python
* Loops & Conditions
* Lists & Functions

---

## ▶️ How to Run

### Option 1 (Python file)

```bash
python kaun_banega_crorepati.py
```

### Option 2 (Notebook)

Run all cells in `.ipynb`
