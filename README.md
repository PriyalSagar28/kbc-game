# KBC Quiz Game 🎯

A Python-based CLI quiz game inspired by Kaun Banega Crorepati (KBC).

---

## 🚀 Features

* 10 Multiple-choice questions
* Money reward system
* Safe levels (₹10,000 and ₹3,20,000)
* Quit option anytime
* Input validation

---

## 🛠 Tech Used

* Python
* Loops & Conditions
* Lists & Functions

---

## ▶️ How to Run

### Option 1 (Python file)

```bash
python kbc_game.py
```

### Option 2 (Notebook)

Run all cells in `.ipynb`
